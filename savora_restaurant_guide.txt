BRAND

TAGLINE

PROJECT TYPE
Premium Singapore Restaurant & Dining Experience

TECH STACK
- Next.js 15
- React 19
- TypeScript
- Tailwind CSS v4
- Framer Motion
- GSAP
- Lenis Smooth Scroll

DESIGN GOAL

Create a luxury editorial dining experience.

DO NOT BUILD:
- Generic restaurant template
- Food delivery app UI
- Dashboard layout
- Statistics counters
- Hero + cards + footer template
- Repetitive navigation used in previous projects

UI DIRECTION

Inspired by:
- Michelin Guide
- Luxury hospitality websites
- Editorial magazines
- Modern Dribbble restaurant concepts

NAVIGATION

Use a minimal floating navigation.

Transparent initially.
Appears on scroll.
Elegant micro-interactions.
